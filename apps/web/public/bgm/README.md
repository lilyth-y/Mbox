# Cube BGM assets

Royalty-free MP3 files for automatic BGM mux on MP4 export.

| File | Track id | Mixkit source |
|------|----------|---------------|
| `cinematic-romantic.mp3` | 시네마 로맨틱 | Romantic · Francisco Alvear |
| `piano-slideshow.mp3` | 피아노 슬라이드 | Piano Reflections · Ahjay Stelino |
| `romantic-wedding.mp3` | 로맨틱 웨딩 피아노 | Wedding 01 · Francisco Alvear |
| `bridal-chorus.mp3` | 클래식 입장곡 스타일 | Classical vibes 5 · Grigoriy Nuzhny |

## Install

```bash
npm run download:commercial-bgm
npm run sync:user-assets   # optional: refresh user BGM catalog
```
