# 웨딩 홀로그램 오퍼레이터 (React)

`/wedding-simple/` 는 **React `WeddingSimpleDashboard`** 로 제공됩니다 (MediaSection · 내 파일 업로드/삭제 · workspace BGM 포함).

## 실행

```bash
npm run dev
```

브라우저: `http://localhost:5173/wedding-simple/`  
또는 `start.bat` 더블 클릭.

빌드 산출물: `dist/wedding-simple.html` (+ `dist/wedding-simple/index.html` 리다이렉트)

## 레거시

`app.js`, `cube-core.js` 등은 이전 정적 버전 잔여물입니다. 신규 기능은 React 대시보드에만 추가합니다.
