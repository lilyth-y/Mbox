\section{Conclusions}
\begin{itemize}
  \item \textbf{Segment trim fix} (filter trim vs input -ss): E1/E2 PASS.
  \item \textbf{BlendMode Screen}: improves cube-segment visibility (E4 PASS); not default globally (wedding photo segment untested).
  \item \textbf{BGM}: \texttt{piano-slideshow.mp3} fixes silent output (E5 PASS).
  \item \textbf{Cube scale}: edge-luma metric insensitive for dark rose; 1.25 vs 1.0 difference $<1\%$ --- visual QA required.
  \item \textbf{EHI}: composite file is not entrance hologram export; separate Mbox track.
\end{itemize}
