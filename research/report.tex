\section{Goal}
Validate the Gemini analysis, background edit, crop, gallery, and cube pipeline behind mbox.

\section{Hypothesis}
A server-proxied Gemini workflow can reproduce the single-file prototype while keeping API credentials off the client.

\section{Methodology}
\begin{itemize}
  \item Tier 1 checks end-to-end smoke execution on fixed samples.
  \item Tier 2 reviews label, center, prompt, and crop quality on a small subset.
  \item Tier 3 compares latency and success rate on fixed inputs and prompts.
  \item Each experiment changes only one variable at a time.
\end{itemize}

\section{Theoretical bounds}
\begin{itemize}
  \item Analysis JSON succeeds when the model returns valid structured output.
  \item Background editing quality is bounded by object preservation and scene consistency.
  \item Crop quality is bounded by center-coordinate accuracy and source aspect ratio.
  \item Cube rendering is bounded by browser texture loading and animation frame budget.
\end{itemize}
